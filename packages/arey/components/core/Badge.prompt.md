Status pill — the only place semantic colour appears in arey.

```jsx
<Badge tone="success" dot>Ready</Badge>
<Badge tone="danger" dot>Failed</Badge>
<Badge tone="warning" dot>Building</Badge>
<Badge mono size="sm">v4.2.0</Badge>
<Badge tone="outline">Preview</Badge>
```

Sentence case, one or two words. Never carries an action — that's a Tag with `onRemove`.
